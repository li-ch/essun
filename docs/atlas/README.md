# Design-space atlas — catalog index

Status: **APPROVED as E0 product content** (2026-10-29).
Evidence level **E0 only**: every table behind these links compares
closed-form L0/L0.5 analytical identities under explicit free parameters.
The pages state arithmetic facts of the models — traffic and completion
identities, their exact-fraction deltas, and payload sizes where two
identities in one cell cross. Nothing here is measured on hardware,
nothing is standard-derived, and no claim, label, or README status
upgrades from this catalog.

One stage per **(rank class x algorithm family)** cell. Rank classes:
4, 8, 16, 32, 64. Families: ring, crossbar, torus (all factorizations per
rank count), recursive-doubling, phase collectives, L0.5. Within every
rank class the **ring cell is the baseline**: each cell's page reports
deltas of its identities against the ring identity at the same payload
size.

## Shared conventions (every cell, the fairness rule)

- **Message grid** — the same 12 sizes in every cell: 4 KiB → 64 MiB as
  the maximally even power-of-two ladder (exponents
  {12,13,14,16,17,18,20,21,22,24,25,26}; ratio pattern x2,x2,x4 repeating).
  Every size is divisible by 4096, hence by every rank count and torus
  factorization here — the `A-L*-DIV` guards never reject a grid point,
  so crossovers are found on a common grid.
- **Free parameters equal across algorithms** in a cell — B = 64 bytes/ns
  and L = 200 ns in every topology file; ranks fixed per rank class; W1
  Dense TP Decode shape (layers 2 x steps 3 = 6 AllReduce ops). The L0.5
  family's one extra free parameter, the injection (serialization) rate
  I, is fixed by the same rule at the registered convention value
  **I = 64 bytes/ns** (A-L05-INJ; equal to B, as in
  `ring8_l05_free_params.yaml` and the GF-05 anchor's
  injection-at-line-rate convention) — declared on
  [4r-l05.md](4r-l05.md), which is the family's atlas convention record.
- **Runs** — one sweep manifest per cell under `experiments/sweeps/`,
  executed by the sweep runner (`make sweep EXP=…`); tables are
  content-addressed under `results/sweeps/<sweep_id>/` (git-ignored by
  design — these pages record the sweep ids and input hashes as the
  provenance record). Identical manifest + code reproduce byte-identical
  tables; each stage's bar includes a deterministic rerun.
