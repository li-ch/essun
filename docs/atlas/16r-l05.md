# Atlas cell 16r-l05 — rank class 16, algorithm family L0.5

Status: **PROPOSED** (atlas content).
Evidence level **E0 only**: every number on this page is the output of a
closed-form L0.5 analytical identity under explicit free parameters.
Nothing here is measured on hardware, no value is standard-derived, and no

of its six families to land.

## What this cell contains

The L0.5 family is the serialized-pipelined-ring AllReduce (backend
module `analytical_l05`, second frontier F1): the SAME unidirectional
ring, workload shape and equal-chunk construction as the L0 ring, with
each of the 2·(r−1) chunk transfers charged an explicit service time —
serialize the chunk at the transmitting NIC, occupy the link, one hop
latency per transfer:

    chunk size         c = M / r                       [c integral: r | M]
    one transfer       s = c/I + c/B + L               [one ring hop]
    completion time    t_L05(M, 16) = 2*(16-1)*s = 30*(M/1024 + M/1024 + 200)

At rank class 16 this family declares exactly ONE identity
(`allreduce_ring_l05` on the serialized-ring fabric
`experiments/topologies/ring16_l05_free_params.yaml`,
topology_id `ring16_l05_free_v1` — the rank-16 mirror of the rank-4 and
rank-8 files, new in this stage); the I -> infinity limit of the SAME
identity is the L0 ring baseline itself (the module's convergence anchor,
pinned as an exact identity by the landed golden tests), so the baseline
this page deltas against is the I = infinity member of this very family —
as at rank 4 and rank 8, the only cell in the rank class whose baseline
is an in-family limit rather than a different algorithm.

Identity executed (per op, message M, ranks r = 16, exact Fractions):

    per-rank wire traffic  T(M, 16) = 2*(16-1)/16 * M = 15M/8            (UNCHANGED from the L0 ring — serialization moves no bytes)
    completion time        t_L05(M, 16) = 30*(M/1024 + M/1024 + 200)
                                        = 15M/256 + 6000 ns             (I = 64 bytes/ns = B)
    serialization term     t_L05 - t_L0 = 2*(16-1)/16 * M / I = 15M/512 ns (exact, re-checked per op by the model)

Free parameters (equal across every config in this cell, and equal to
the other atlas rank classes): B = 64 bytes/ns, L = 200 ns, ranks = 16,
W1 Dense TP Decode shape (layers 2 x steps 3 = 6 AllReduce ops per
config). The family's one additional free parameter — the injection
(serialization) rate I — is fixed by the atlas fairness rule at the
registered convention value **I = 64 bytes/ns** (A-L05-INJ,
`experiments/vertical_slice/assumptions_l05.yaml`), declared on the
family's convention record [4r-l05.md](4r-l05.md): I = 64 = B, the
serializing NIC runs at link line rate. This cell's own topology file
(`ring16_l05_free_params.yaml`) carries I = 64 in-file, the rank-16
mirror of `ring8_l05_free_params.yaml` — the file the convention was
derived from. All values are free parameters or model arithmetic — none
is measured or standard-derived.

Six arithmetic facts drive the whole cell, all visible in the identities
(ring baseline: T = 15M/8, t_L0 = 15M/512 + 6000 — [16r-ring.md](16r-ring.md)):

1. **At I = B the serialized identity is the baseline with a doubled
   bandwidth slope: t_L05(M) = t_L0(2M) exactly** (15M/256 + 6000 =
   15·(2M)/512 + 6000, verified at all 12 grid sizes). The latency chain
   is UNCHANGED (2·(r−1)·L = 6000), so both curves share the exact
   M = 0 intercept and delta(0) = 0. The doubling is visible
   digit-for-digit in the table: the L0.5 CCT column at each grid point
   equals the ring column one doubling up — eight in-grid coincidences
   (6240 = ring@8 KiB, 6480 = ring@16 KiB, 9840 = ring@128 KiB,
   13680 = ring@256 KiB, 67440 = ring@2 MiB, 128880 = ring@4 MiB,
   989040 = ring@32 MiB, 1972080 = ring@64 MiB); the four x4 rungs of
   the ladder land off-grid (6960 = ring@32 KiB, 21360 = ring@512 KiB,
   251760 = ring@8 MiB, 3938160 = ring@128 MiB).
2. **The serialization term equals the ring's own bandwidth term at
   every M.** With I = B, 2(r−1)/r·M/I = 15M/512 = the bandwidth term of
   t_L0 — per transfer, c/I = c/B = M/1024 (serialization and wire are
   each exactly half the non-latency transfer time). Hence the delta
   identity

       delta(M) = (t_L05 - t_L0) / t_L0 = (15M/512) / (15M/512 + 6000) = M / (M + 204800)

   The closed form **delta_r(M) = M/(M + L·B·r)** — the payload measured
   in units of the ring's own balance point M* = L·B·r; equivalently the
   baseline's bandwidth fraction (one minus its latency fraction). The
   rank-4 and rank-8 cells' delta columns obey the same law with 51200
   and 102400, so this cell exercises the law at a THIRD rank class.
   Strictly increasing, bounded in (0, 1), delta(0) = 0, large-M limit
   exactly 1.
3. **Every delta is positive — with this cell, the slower side of the
   baseline is populated at rank 16 too, by L0.5 alone.** Crossbar,
   torus (both factorizations, below the three-way crossover), doubling
   and phases all delta negative against the ring AllReduce; L0.5 pays a
   strictly positive serialization term at every M > 0 and every finite
   I, by the module's pinned convergence identity. The catalog's slower
   side is this family's alone at all three landed rank classes.
4. **M = 204800 B is now a FOUR-fold special point of the 16-rank atlas.**
   After 16r-phases it was three-fold (ring AR balance, ring-phase
   balance, torus three-way crossover — all at M* = L·B·r = 204800 B =
   200 KiB); L0.5 adds delta(M*) = exactly +1/2, and delta(M*) = 1/2 is
   rank-independent (structural at every r by fact 2's closed form) —
   the exact mirror of the four-fold 51200 B point at rank 4 and 102400 B
   at rank 8. The L0.5 identity balances its own combined
   bandwidth+serialization term 15M/256 against 6000 ns at M = 102400 B
   = M*/2, between the 64 KiB and 128 KiB grid points — and 102400 B is
   exactly the RANK-8 ring balance point: the L0.5 balance ladder
   L·B·r/2 = {25600 (r=4), 51200 (r=8), 102400 (r=16)} walks the ring
   balance ladder one rank down, its third consecutive rung. The 16-rank
   transition book now reads {204800/15 ≈ 13653.33 (crossbar, = M*/15),
   819200/15 ≈ 54613.33 (doubling AR and doubling phase, = 4M*/15),
   102400 (L0.5 at I = B, = M*/2), 204800 (ring AR, ring phase, torus
   three-way crossover, L0.5 half-point)} B — the ladder {1, 4, 7.5, 15}
   in units of M*/15.
5. **THE 8r-l05 PREDICTION CONFIRMED — the half-saturation shift law:
   delta_16(M) = delta_8(M/2) identically** (M/(M+204800) =
   (M/2)/(M/2+102400); verified at all 12 sizes, exact-string equal
   against the landed 8r-l05 table). The ladder makes it visible: the
   16-rank delta column {1/51, 1/26, 2/27, 8/33, 16/41, 32/57, 128/153,
   256/281, 512/537, 2048/2073, 4096/4121, 8192/8217} reuses the rank-8
   column's entries one rung down wherever M/2 is on-grid ({1/26, 2/27,
   16/41, 32/57, 256/281, 512/537, 4096/4121, 8192/8217} shared); the
   four new entries {1/51, 8/33, 128/153, 2048/2073} sit where M/2
   crosses an x4 rung — including the ladder's new floor 1/51, the
   1/26-analog predicted by the law. By the same law delta_16(M) =
   delta_4(M/4) (one rank class further: saturation in M halves per
   doubling of r). Consequently delta_16(M) < delta_8(M) at every grid
   size — the SAME relative serialization disagreement (the baseline's
   own bandwidth term, at every rank) is diluted by the longer latency
   chain (6000 vs 2800 ns); the ratio delta_16/delta_8 =
   (M+102400)/(M+204800) climbs 26/51 → 16409/16434 toward 1.
6. **The absolute disagreement GROWS with rank while the relative one
   shrinks.** The serialization term itself rises from 7M/256 (r=8) to
   15M/512 (r=16) — exactly ×15/14, the ratio of serialized transfers
   (30 = 2·15 vs 14 = 2·7) — yet fact 5 shows every delta smaller at
   rank 16. More hops to serialize over, spread over a longer latency
   chain: the delta measures the latency-chain dilution, not the term
   (the rung ladder ×7/6 (4→8) → ×15/14 (8→16) tracks 2(r−1) exactly).

## Crossover message sizes

**None in this cell.** A crossover is a payload size where two
identities in one cell swap ordering. The cell contains one declared
finite-I identity; the family's only other member is the I -> infinity
limit, which IS the ring baseline (an exact equality, not a crossing —
the serialization term is strictly positive at every M > 0 and finite I,
zero only in the limit, so the two curves touch only at M = 0 and never
swap). Against the baseline the delta is positive and strictly
increasing on the whole grid — sign never changes, no crossing exists.
Recorded honestly rather than forced; the 16-rank catalog's non-trivial
crossovers remain the torus cell's three-way concurrent point at
M = 204800 B ([16r-torus.md](16r-torus.md)), which fact 4 above shows is
also this cell's delta = +1/2 point.
