## What this cell contains

The L0.5 family is the serialized-pipelined-ring AllReduce (backend
module `analytical_l05`, second frontier F1): the SAME unidirectional
ring, workload shape and equal-chunk construction as the L0 ring, with
each of the 2·(r−1) chunk transfers charged an explicit service time —
serialize the chunk at the transmitting NIC, occupy the link, one hop
latency per transfer:

    chunk size         c = M / r                       [c integral: r | M]
    one transfer       s = c/I + c/B + L               [one ring hop]
    completion time    t_L05(M, 64) = 2*(64-1)*s = 126*(M/4096 + M/4096 + 200)

At rank class 64 this family declares exactly ONE identity
(`allreduce_ring_l05` on the serialized-ring fabric
`experiments/topologies/ring64_l05_free_params.yaml`,
topology_id `ring64_l05_free_v1` — the rank-64 mirror of the rank-4,
rank-8, rank-16 and rank-32 files, new in this stage); the I -> infinity
limit of the SAME identity is the L0 ring baseline itself (the module's
convergence anchor, pinned as an exact identity by the landed golden
tests), so the baseline this page deltas against is the I = infinity
member of this very family — as at rank 4, rank 8, rank 16 and rank 32,
the only cell in the rank class whose baseline is an in-family limit
rather than a different algorithm.

Identity executed (per op, message M, ranks r = 64, exact Fractions):

    per-rank wire traffic  T(M, 64) = 2*(64-1)/64 * M = 63M/32            (UNCHANGED from the L0 ring — serialization moves no bytes)
    completion time        t_L05(M, 64) = 126*(M/4096 + M/4096 + 200)
                                        = 63M/1024 + 25200 ns             (I = 64 bytes/ns = B)
    serialization term     t_L05 - t_L0 = 2*(64-1)/64 * M / I = 63M/2048 ns (exact, re-checked per op by the model)

Free parameters (equal across every config in this cell, and equal to
the other atlas rank classes): B = 64 bytes/ns, L = 200 ns, ranks = 64,
W1 Dense TP Decode shape (layers 2 x steps 3 = 6 AllReduce ops per
config). The family's one additional free parameter — the injection
(serialization) rate I — is fixed by the atlas fairness rule at the
registered convention value **I = 64 bytes/ns** (A-L05-INJ,
`experiments/vertical_slice/assumptions_l05.yaml`), declared on the
family's convention record [4r-l05.md](4r-l05.md): I = 64 = B, the
serializing NIC runs at link line rate. This cell's own topology file
(`ring64_l05_free_params.yaml`) carries I = 64 in-file, the rank-64
mirror of `ring8_l05_free_params.yaml` — the file the convention was
derived from. All values are free parameters or model arithmetic — none
is measured or standard-derived.

Six arithmetic facts drive the whole cell, all visible in the identities
(ring baseline: T = 63M/32, t_L0 = 63M/2048 + 25200 —
[64r-ring.md](64r-ring.md)):

1. **At I = B the serialized identity is the baseline with a doubled
   bandwidth slope: t_L05(M) = t_L0(2M) exactly** (63M/1024 + 25200 =
   63·(2M)/2048 + 25200, verified at all 12 grid sizes). The latency
   chain is UNCHANGED (2·(r−1)·L = 126·200 = 25200), so both curves share
   the exact M = 0 intercept and delta(0) = 0. The doubling is visible
   digit-for-digit in the table: the L0.5 CCT column at each grid point
   equals the ring column one doubling up — eight in-grid coincidences
   (25452 = ring@8 KiB, 25704 = ring@16 KiB, 29232 = ring@128 KiB,
   33264 = ring@256 KiB, 89712 = ring@2 MiB, 154224 = ring@4 MiB,
   1057392 = ring@32 MiB, 2089584 = ring@64 MiB); the four x4 rungs of
   the ladder land off-grid (26208 = ring@32 KiB, 41328 = ring@512 KiB,
   283248 = ring@8 MiB, 4153968 = ring@128 MiB).
2. **The serialization term equals the ring's own bandwidth term at
   every M.** With I = B, 2(r−1)/r·M/I = 63M/2048 = the bandwidth term
   of t_L0 — per transfer, c/I = c/B = M/4096 (serialization and wire
   are each exactly half the non-latency transfer time). Hence the delta
   identity

       delta(M) = (t_L05 - t_L0) / t_L0 = (63M/2048) / (63M/2048 + 25200) = M / (M + 819200)

   The closed form **delta_r(M) = M/(M + L·B·r)** — the payload measured
   in units of the ring's own balance point M* = L·B·r; equivalently the
   baseline's bandwidth fraction (one minus its latency fraction). The
   rank-4, rank-8, rank-16 and rank-32 cells' delta columns obey the same
   law with 51200, 102400, 204800 and 409600, so this cell exercises the
   law at a FIFTH rank class — the ladder's terminal one. Strictly
   increasing, bounded in (0, 1), delta(0) = 0, large-M limit exactly 1.
3. **Every delta is positive — with this cell, the slower side of the
   baseline is populated at rank 64 too, by L0.5 alone, completing the
   pattern at all five rank classes.** Crossbar, torus (all three
   factorizations, below the four-way crossover), doubling and phases all
   delta negative against the ring AllReduce; L0.5 pays a strictly
   positive serialization term at every M > 0 and every finite I, by the
   module's pinned convergence identity. The catalog's slower side is
   this family's alone at every landed rank class — 4, 8, 16, 32 and now
   64, the complete ladder.
4. **M = 819200 B is a FOUR-fold special point of the 64-rank atlas —
   the fold the 64r-phases page left pending, now tested and confirmed.**
   After 64r-phases it was three-fold (ring AR balance, ring-phase
   balance, torus FOUR-way crossover — all at M* = L·B·r = 819200 B =
   800 KiB); L0.5 adds delta(M*) = exactly +1/2, and delta(M*) = 1/2 is
   rank-independent (structural at every r by fact 2's closed form) —
   the exact mirror of the four-fold 51200 B point at rank 4, 102400 B
   at rank 8, 204800 B at rank 16 and 409600 B at rank 32. Reading every
   LOWER rank class's four-fold point off this cell's curve gives the

   102400 B -> 1/9, 204800 B -> 1/5, 409600 B -> 1/3, 819200 B -> 1/2 —

## Crossover message sizes

**None in this cell.** A crossover is a payload size where two
identities in one cell swap ordering. The cell contains one declared
finite-I identity; the family's only other member is the I -> infinity
limit, which IS the ring baseline (an exact equality, not a crossing —
the serialization term is strictly positive at every M > 0 and finite I,
zero only in the limit, so the two curves touch only at M = 0 and never
swap). Against the baseline the delta is positive and strictly
increasing on the whole grid — sign never changes, no crossing exists.
Recorded honestly rather than forced; the 64-rank catalog's non-trivial
crossovers remain the torus cell's four-way concurrent point at
M = 819200 B ([64r-torus.md](64r-torus.md)), which fact 4 above shows is
also this cell's delta = +1/2 point.
