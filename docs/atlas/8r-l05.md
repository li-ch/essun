# Atlas cell 8r-l05 — rank class 8, algorithm family L0.5

Status: **PROPOSED** (atlas content).
Evidence level **E0 only**: every number on this page is the output of a
closed-form L0.5 analytical identity under explicit free parameters.
Nothing here is measured on hardware, no value is standard-derived, and no

## What this cell contains

The L0.5 family is the serialized-pipelined-ring AllReduce (backend
module `analytical_l05`, second frontier F1): the SAME unidirectional
ring, workload shape and equal-chunk construction as the L0 ring, with
each of the 2·(r−1) chunk transfers charged an explicit service time —
serialize the chunk at the transmitting NIC, occupy the link, one hop
latency per transfer:

    chunk size         c = M / r                       [c integral: r | M]
    one transfer       s = c/I + c/B + L               [one ring hop]
    completion time    t_L05(M, 8) = 2*(8-1)*s = 14*(M/(8I) + M/512 + 200)

At rank class 8 this family declares exactly ONE identity
(`allreduce_ring_l05` on the serialized-ring fabric
`experiments/topologies/ring8_l05_free_params.yaml`,
topology_id `ring8_l05_free_v1`); the I -> infinity limit of the SAME
identity is the L0 ring baseline itself (the module's convergence anchor,
pinned as an exact identity by the landed golden tests), so the baseline
this page deltas against is the I = infinity member of this very family —
as at rank 4, the only cell in the rank class whose baseline is an
in-family limit rather than a different algorithm.

Identity executed (per op, message M, ranks r = 8, exact Fractions):

    per-rank wire traffic  T(M, 8) = 2*(8-1)/8 * M = 7M/4             (UNCHANGED from the L0 ring — serialization moves no bytes)
    completion time        t_L05(M, 8) = 14*(M/512 + M/512 + 200)
                                        = 7M/128 + 2800 ns            (I = 64 bytes/ns = B)
    serialization term     t_L05 - t_L0 = 2*(8-1)/8 * M / I = 7M/256 ns (exact, re-checked per op by the model)

Free parameters (equal across every config in this cell, and equal to
the other atlas rank classes): B = 64 bytes/ns, L = 200 ns, ranks = 8,
W1 Dense TP Decode shape (layers 2 x steps 3 = 6 AllReduce ops per
config). The family's one additional free parameter — the injection
(serialization) rate I — is fixed by the atlas fairness rule at the
registered convention value **I = 64 bytes/ns** (A-L05-INJ,
`experiments/vertical_slice/assumptions_l05.yaml`), declared on the
family's convention record [4r-l05.md](4r-l05.md): I = 64 = B, the
serializing NIC runs at link line rate. This cell's own topology file
(`ring8_l05_free_params.yaml`) is the file that convention was derived
from — the rank-8 fabric carries I = 64 in-file, no new declaration.
All values are free parameters or model arithmetic — none is measured or
standard-derived.

Six arithmetic facts drive the whole cell, all visible in the identities
(ring baseline: T = 7M/4, t_L0 = 7M/256 + 2800 — [8r-ring.md](8r-ring.md)):

1. **At I = B the serialized identity is the baseline with a doubled
   bandwidth slope: t_L05(M) = t_L0(2M) exactly** (7M/128 + 2800 =
   7·(2M)/256 + 2800, verified at all 12 grid sizes). The latency chain
   is UNCHANGED (2·(r−1)·L = 2800), so both curves share the exact
   M = 0 intercept and delta(0) = 0. The doubling is visible
   digit-for-digit in the table: the L0.5 CCT column at each grid point
   equals the ring column one doubling up — eight in-grid coincidences
   (3024 = ring@8 KiB, 3248 = ring@16 KiB, 6384 = ring@128 KiB,
   9968 = ring@256 KiB, 60144 = ring@2 MiB, 117488 = ring@4 MiB,
   920304 = ring@32 MiB, 1837808 = ring@64 MiB); the three x4 rungs of
   the ladder land off-grid (3696 = ring@32 KiB, 17136 = ring@512 KiB,
   232176 = ring@8 MiB).
2. **The serialization term equals the ring's own bandwidth term at
   every M.** With I = B, 2(r−1)/r·M/I = 7M/256 = the bandwidth term of
   t_L0 — per transfer, c/I = c/B = M/512 (serialization and wire are
   each exactly half the non-latency transfer time). Hence the delta
   identity

       delta(M) = (t_L05 - t_L0) / t_L0 = (7M/256) / (7M/256 + 2800) = M / (M + 102400)

   The closed form **delta_r(M) = M/(M + L·B·r)** — the payload measured
   in units of the ring's own balance point M* = L·B·r; equivalently the
   baseline's bandwidth fraction (one minus its latency fraction). The
   rank-4 cell's delta column obeys the same law with 51200 = M*_4, so
   this cell exercises the law at a second rank class. Strictly
   increasing, bounded in (0, 1), delta(0) = 0, large-M limit exactly 1.
3. **Every delta is positive — with this cell, the slower side of the
   baseline is populated at rank 8 too, by L0.5 alone.** Crossbar,
   torus (below its crossover), doubling and phases all delta negative
   against the ring AllReduce; L0.5 pays a strictly positive
   serialization term at every M > 0 and every finite I, by the module's
   pinned convergence identity. The catalog's slower side is this
   family's alone at both landed rank classes.
4. **M = 102400 B is now a FOUR-fold special point of the 8-rank atlas.**
   After 8r-phases it was three-fold (ring AR balance, ring-phase
   balance, torus crossover — all at M* = L·B·r = 102400 B = 100 KiB);
   L0.5 adds delta(M*) = exactly +1/2, and delta(M*) = 1/2 is
   rank-independent (structural at every r by fact 2's closed form) —
   the exact mirror of the four-fold 51200 B point at rank 4. The L0.5
   identity balances its own combined bandwidth+serialization term
   7M/128 against 2800 ns at M = 51200 B = M*/2, inside the ladder's
   first x4 interval (16 KiB -> 64 KiB) — and 51200 B is exactly the
   RANK-4 ring balance point: the L0.5 balance ladder
   L·B·r/2 = {25600 (r=4), 51200 (r=8)} walks the ring balance ladder
   one rank down. The 8-rank transition book now reads
   {102400/7 ≈ 14628.6 (crossbar, = M*/7), 307200/7 ≈ 43885.7 (doubling
   AR and doubling phase, = 3M*/7), 51200 (L0.5 at I = B, = M*/2),
   102400 (ring AR, ring phase, torus crossover, L0.5 half-point)} B.
5. **The rank-8 delta curve is the rank-4 delta curve stretched by
   exactly 2 in M: delta_8(M) = delta_4(M/2) identically**
   (M/(M+102400) = (M/2)/(M/2+51200); verified at all 12 sizes). The
   ladder makes it visible: the 8-rank delta column
   {1/26, 2/27, 4/29, 16/41, 32/57, 64/89, 256/281, 512/537, 1024/1049,
   4096/4121, 8192/8217, 16384/16409} reuses the rank-4 column's entries
   one rung down wherever M/2 is on-grid ({2/27, 4/29, 32/57, 64/89,
   512/537, 1024/1049, 8192/8217, 16384/16409} shared); the four new
   entries {1/26, 16/41, 256/281, 4096/4121} sit where M/2 crosses an x4
   rung. Consequently delta_8(M) < delta_4(M) at every grid size — the
   SAME relative serialization disagreement (the baseline's own
   bandwidth term, at both ranks) is diluted by the doubled latency
   chain (2800 vs 1200 ns); the ratio delta_8/delta_4 =
   (M+51200)/(M+102400) climbs 27/52 → 32793/32818 toward 1.
6. **The absolute disagreement GROWS with rank while the relative one
   shrinks.** The serialization term itself rises from 3M/128 (r=4) to
   7M/256 (r=8) — exactly ×7/6, the ratio of serialized transfers
   (14 = 2·7 vs 6 = 2·3) — yet fact 5 shows every delta smaller at rank
   8. More hops to serialize over, spread over a longer latency chain:
   the delta measures the latency-chain dilution, not the term.

One-in-parameter interpolation (arithmetic fact of the family, not a
sweep): t_L05 is linear in 1/I, pinned at the two ends by the convergence
anchor — I -> infinity returns the baseline identity exactly (0
serialization), the executed grid is I = 64 — and every finite I lands
strictly above the baseline at M > 0. The cell executes one I value
because the fairness rule fixes every free parameter across a cell's
grid; the 1/I ladder is recorded as the family's shape, not a landed
column (same statement as the rank-4 cell — rank-independent).

## Crossover message sizes

**None in this cell.** A crossover is a payload size where two
identities in one cell swap ordering. The cell contains one declared
finite-I identity; the family's only other member is the I -> infinity
limit, which IS the ring baseline (an exact equality, not a crossing —
the serialization term is strictly positive at every M > 0 and finite I,
zero only in the limit, so the two curves touch only at M = 0 and never
swap). Against the baseline the delta is positive and strictly
increasing on the whole grid — sign never changes, no crossing exists.
Recorded honestly rather than forced; the 8-rank catalog's non-trivial
crossover remains the torus cell's M = 102400 B
([8r-torus.md](8r-torus.md)), which facts 2 and 4 above show is also
this cell's delta = +1/2 point.
