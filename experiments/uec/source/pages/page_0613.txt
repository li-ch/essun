If the local port does not support CSIG but does support the UE Link Options LLDP TLV csig-capable 
object, then it MUST set the local UE Link Option LLDP TLV csig-capable object to CSIG-NO. If the local 
port supports only compact CSIG tags and also supports the csig-capable object, then it MUST set the 
local UE Link Option LLDP TLV csig-capable object to CSIG-COMPACT. If the local port supports both 
compact and wide CSIG tags and the csig-capable object, then it MUST set the local UE Link Option LLDP 
TLV csig-capable object to CSIG-COMPACT-WIDE. 
Provided the system has enabled the use of LLDP for CSIG configuration, a port MUST perform the 
operations described in Table 4-7. A system MAY provide capabilities to override the LLDP configuration 
for CSIG on a port or switch; however, if the UE Link Option LLDP TLV csig-capable object is supported it 
MUST still be set consistent with the system configuration (i.e., if CSIG is disabled by a local system 
configuration then csig-capable is set to CSIG-NO even if the switch is capable of processing CSIG tags).
