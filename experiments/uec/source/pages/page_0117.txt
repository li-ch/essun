2.2.5.4.3 fi_rma() APIs 
The fi_rma() APIs are used to perform remote memory access operations. There are APIs for read and 
write operations.  
The fi_rma() APIs are NOT supported for FI_EP_DGRAM endpoints. 
Table 2-25 summarizes the fi_rma() API requirements and shows the mapping of the APIs to the UET SES 
opcodes.
