3.7.11 TSS over the UFH_32 Header 
The primary goal for the Unified Local profile is to reduce the wire overhead and maintain 8-byte 
alignment to facilitate efficient mapping at the Ethernet layer.   
The regular TSS mode is supported when using the UFH_32 header. The regular TSS mode MUST be 
supported if TSS is supported in the Unified Local profile.TSS Packet Processing 
UET defines three types of encapsulations: 
• Directly over IP using the IP header to identify the UET protocol. 
• UDP encapsulation over IP, where the UDP port number of 4793 is used to identify the UET 
protocol. 
• Directly over UFH_32 where the EtherType 0xE790 is used to identify the UET.
