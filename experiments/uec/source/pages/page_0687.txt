5.3.2 UE Organizationally Specific LLDP TLVs 
The UE organizationally specific LLDP TLVs are used to: 
i) Advertise capabilities available at a UE Link. 
ii) Negotiate and activate common link capabilities. 
The UEC defines the UE Link Negotiation Options TLV and the UE Link CBFC TLV for configuration of UE 
link features. The UE Link Negotiation Options TLV is used to discover and configure advanced UE link 
capabilities. The UE Link Negotiation CBFC TLV is used to discover and configure UE link credit-based 
flow control (CBFC). 
5.3.2.1 UE Link Negotiation Options TLV (Options TLV) 
The UE Link Negotiation Options TLV is exchanged via LLDP and conforms to the LLDP TLV specification 
[1] for organizationally specific TLVs. The UE Link Negotiation Options TLV is also called the Options TLV 
within this specification. 
The Options TLV is used to advertise the following UE link features: 
• Link layer retry (LLR): Provides link-level re-transmissions for packets with errors. 
• Inter-packet gap reduction (IPGR): Also known as idle reduction. Reduces the number of idle 
bytes between frames. 
• Congestion signaling (CSIG): L2 tag used to providing telemetry. 
• Unified forwarding header (UFH): Provides a compressed L2/L3 header.
