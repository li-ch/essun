3.6.18.6.3 PCM Telegrams 
PCM algorithms can exchange out-of-band messages with software running on the local node as well as 
the peer CCC using optional telegrams. The structure and use of telegrams is algorithm-specific; they 
may be used in any situation in which coordination or information exchange between the algorithm and 
the host or remote peer is required. 
Telegrams are fixed-size structures of up to 30 bytes in length, composed of one or more fields. An 
algorithm can define multiple types of telegrams. There is no definition-level distinction between 
telegrams exchanged locally or with peers, although support is provided for an algorithm to distinguish 
between the source of received telegrams. Telegrams are defined using the YAML schema provided in 
Section 3.6.18.8.5. Telegrams of different types are uniquely identified both locally and remotely by the 
value of the structure type_id field.
