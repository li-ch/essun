3.3.2 Buffer Addressing Mechanisms 
Implementations of all profiles MUST conform to all basic buffer addressing schemes (described in SES 
Section 3.4.2.3) except for matching (described in SES Section 3.4.2.3.5). Implementations of all profiles 
MUST support the use of memory keys for UET_WRITE operations. All implementations MUST support 
the use of memory keys for UET_READ and UET_ATOMIC operations if RMA read is supported. Exact 
matching support may be implemented using wild-card matching.

3.3.3 Authorization 
All profiles MUST implement the authorization semantics (SES Section 3.4.2.4). All profiles MUST be able 
to insert the JobID according to SES Section 3.4.2.4.1. The profile implementation MUST check the JobID 
before allowing buffer access. All profiles MUST support at least one JobID per FEP.
