4. If pds.flags.syn = 0, perform the following checks 
a. If pds.dpdcid does not match an active PDCID, send a NACK with pds.nack_code = 
UET_INV_DPDCID. 
b. Confirm the network header matches the expected source FA (ip.src_addr); if ip.src_addr 
doesn’t match then send a NACK with pds.nack_code = UET_PDC_HDR_MISMATCH 
c. Confirm the delivery mode (RUD/ROD/RODL) matches; if not, drop the packet, record error 
event and send a NACK with pds.nack_code = UET_PDC_MODE_MISMATCH. 
d. Check the PSN (pds.psn)—if outside expected window (Section 3.5.12.2), generate a NACK 
with pds.nack_code = UET_PSN_OOR_WINDOW. 
i. If the PDC type is ROD or RODL, check if the pds.psn matches the Expected_PSN—if 
the PSN does not match, transmit a NACK with pds.nack_code = UET_ROD_OOO 
(See Section 3.5.21.1).

A NACK MUST NOT be used to create a PDC except when the target sends a NACK with 
pds.nack_code = UET_NEW_START_PSN or UET_ROD_OOO.  In those cases, a PDC is created when a 
packet arrives with pds.flags.syn set and no PDC yet exists.
