Because different signal types often carry values of differing magnitudes, quantization bucket ranges for 
compact CSIG tags are configured separately for each signal type. The switch control plane sets buckets’ 
minimum and maximum values during configuration. 
The compact CSIG tag includes 5 bits of signal value. There are 25 = 32 quantized values, each 
corresponding to one bucket. Before quantizing a raw signal’s value, the switch hardware MUST ensure 
that the raw signal’s value is of a precision (length in bits) that matches the precision of that signal’s 
quantization bucket ranges. If the precision of the raw signal’s value exceeds that of the signal’s 
quantization bucket ranges by e bits, the hardware right bit-shifts the raw signal’s value by e bits. No bit-
shift is performed if the precision of the raw signal value is less than or equal to that of the signal’s 
quantization bucket ranges. The hardware then performs a simple range check on the resulting signal 
value to map the raw value to the bucket in which it falls. The index of that bucket is the quantized 
value. 
If a raw signal value is less than the minimum bound of bucket index 0 (the least raw signal value 
represented in the quantization’s configuration), it is out-of-range low, and the switch hardware MUST 
quantize that raw signal value as falling within bucket index 0. If a raw signal value is greater than the 
maximum bound of bucket index 31 (the greatest raw signal value represented in the quantization’s 
configuration), it is out-of-range high, and the switch hardware MUST quantize that raw signal value as 
falling within bucket 31. Switch implementations SHOULD keep event counters for out-of-range low and 
out-of-range high occurrences during quantization. The reporting and use of these counters is 
implementation-specific and outside the scope of this specification.
