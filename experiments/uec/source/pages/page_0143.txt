Figure 2-16 - Verbs Absolute Addressing Model 
UET verbs maintains a flexible access model to MRs for absolute addressing on a server. MR access 
restrictions to a client can be: 
• MR is unrestricted on the PIDonFEP. Any client may access it using any QP that shares the PD. 
• MR is restricted to a client’s JobID (i.e., job-restricted). Only that specific client may access it 
using any QP that shares the PD. 
• MR is restricted to a QP (i.e., RI restricted). Any client may access it using only that QP. 
• MR is restricted to a client’s JobID and restricted to a QP (i.e., RI job restricted). Only that 
specific client may access it using only that QP. 
2.3.3.2 Relative Addressing Model 
 
Informative Text: 
The relative addressing model targets a parallel application running under a specific JobID. Like 
absolute addressing, the PD is associated with a PIDonFEP. Additionally, it’s associated with a JobID. 
All QPs will be associated to their PD’s JobID and PIDonFEP. Similarly, MRs will receive only data that 
target the PD’s JobID and PIDonFEP. Messages sent can target only job keys allocated under the PD. A 
job key may reference a different JobID than that associated with the PD. This enables a parallel 
application to communicate with a server as a client, for example.
