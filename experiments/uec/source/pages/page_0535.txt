3.6.18.5.7 Load Balancing Support 
3.6.18.5.7.1 Per-EV Triggers 
Per-EV triggers enable LB algorithms to react to events associated with specific EVs in the CCC EV table. 
By evaluating conditions and updating state locally in hardware, these triggers eliminate the overhead of 
frequent software callbacks. 
Per-EV triggers are defined using the YAML signal construct configuration schema; the scope field MUST 
be set to EV for every per-EV signal. Multiple EV triggers are supported within a single algorithm 
configuration. Triggers defined in this manner are automatically attached to every EV index in the CCC 
EV table. It is not possible to bind triggers to individual EV indices; the association is uniform across all 
slots in the EV table for the lifetime of the CCC. 
Per-EV signals are evaluated whenever a packet associated with a given EV is transmitted or received. 
On invocation, an algorithm can determine whether any per-EV trigger has fired by checking the macro 
name against the output of uet_trigger_mask(). 
Algorithms can further iterate through the set of fired per-EV triggers using the functions below:
