2.4.17.3 Configuration of an INC Communicator 
This section describes the process of configuring an INC switch for an INC communicator. To perform 
this process the following information is produced by or provided to the IM: 
• The CID. 
• The data plane protocol2. 
• The set of involved SEPs and their fabric addresses. 
• The peering relationships of the SEPs. 
• The data MTU size to be used by the communicator. 
• The scalar integer by which the results are divided when performing sum and scale operations. 
• The TC_low and TC_high traffic classes used by the UET protocol. 
• The bandwidth at which collectives are to be run. 
• The operator ordering mode for the communicator. 
 
2 This specification defines a single data plane protocol (see section 2.4.11); however, other vendor-specific 
protocols are possible.
