3.4.3.9 Header Parsing Guide 
Table 3-20 provides a summary of how to parse the semantic header. The leftmost column contains the 
pds.next_hdr enumeration. For each header enumeration, the middle column enumerates the opcodes 
or opcode types that are used with the next header definition. The rightmost column cross-references to 
the relevant header formats that are used for that opcode or opcode type. In many cases, the header 
consists of a base header and extension header. As shown, a parser can look at the pds.next_hdr field to 
determine the base header structure and the ses.opcode field to determine whether an extension 
header is present and its type. The base header used for deferrable send and ready-to-restart 
operations has the same size and overall structure as the standard request header.
