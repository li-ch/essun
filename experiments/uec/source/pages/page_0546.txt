3.6.18.9 Algorithm Runtime Model 
To guarantee correct operation regardless of implementation, PCM algorithms MUST be written to 
assume the following runtime PCM runtime properties: 
• The PCM subsystem invokes algorithm callback functions when one or more triggers fire due to 
TX, RX, or TIME events, when a transmit EV is required by the data path or when telegrams are 
delivered to the algorithm. 
• The algorithm is invoked once for every set of fired RX, TX, or TIME triggers, or EV transmit 
request or received telegrams. 
• Each invocation delivers only the set of fired triggers, an EV Transmit Request, or a telegram. 
• The PCM subsystem guarantees that for a given CCC there is a maximum of one invocation 
active at any time. 
• For TX or RX events, the set of fired triggers associated with these events is delivered to the 
algorithm in packet order, but events may be skipped. 
o TX events are delivered in packet order. 
o RX events are delivered in packet order. 
o There is no delivery order guarantee between TX and RX events. 
o When events are skipped, no triggers for the associated event are delivered. 
• For TIME events, fired triggers are reliably delivered but may be delayed. 
o There is no delivery order guarantee between different TIME events. 
o There is no delivery order guarantee between TIME, RX, and TX events.
