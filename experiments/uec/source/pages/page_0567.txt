3.7.8 KDF Construction  
The KDF MAY be used to derive keys in the cluster and client-server KDF modes. Note that for client-
server both client and server KDFs are used. The KDF is implemented with single or two input blocks, 
depending on how the source FEP is represented. The single-input block KDF MUST be used for IPv4 
packets or when the SSI is explicitly carried in the packet. For IPv6 packets without an explicit SSI, two 
input blocks MUST be used. 
The KDF algorithm is specified per security domain using the kdf-algo field. The default KDF construction 
MUST be implemented per NIST specification SP 800-108 [40] using AES-CMAC-256 and parameters per 
Table 3-134. Other algorithms and constructions are implementation specific.
