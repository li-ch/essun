5.4.5 UFH and Header Stacking 
UFH retains the use of the EtherType field to identify the next header in the header stack and extend the 
information carried with a packet. For example, VLAN tags can be used to partition a network domain 
for multi-tenancy, MACSEC tags can add link security, and CSIG tags can carry telemetry for congestion 
control or diagnostics. Figure 5-27 shows different tag stacking examples. 
The ordering of tags in the header stack MUST follow Ethernet ordering rules. For example, a VLAN tag if 
present MUST be the first tag on a frame at offset 12. 
Because UFH subsumes the traditional network layer, there is no additional IP header, and tags are 
followed by an L4 transport header. UFH is designed to be used with UDP, UET, and future transports. 
New EtherType encodings are required to identify them.
