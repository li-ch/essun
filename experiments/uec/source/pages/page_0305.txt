Unit: 1 s 
 
If a packet with pds.flags.syn=1 is an inferred loss 
(e.g., based on timeout), a FEP MUST wait 
Syn_Retx_Safety_Time between the original transmit 
of that packet and the closing of that PDC (see Section 
3.5.8.3). The required range is a 24-bit value in 
microseconds. Syn_Retx_Safety_Time SHOULD be set 
to 0 if encryption is enabled or if another anti-replay 
mechanism is enabled.
