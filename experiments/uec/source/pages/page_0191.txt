3.3.7 CMS Congestion Control Algorithms 
CMS specifies two complementary congestion control algorithms, NSCC and RCCC, and supports 
programmable congestion management (PCM) for developing additional or experimental congestion 
control algorithms. For the specified algorithms, the following tables specify the implementation 
requirements in each profile. Independent requirements are provided for best-effort and lossless 
networks. Each implemented algorithm must support a mechanism to disable it at deployment time 
such that either NSCC or RCCC can run in isolation or together if the implementation supports both.
