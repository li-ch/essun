The processing based on error type is defined in the error model in Section 3.5.24. The events leading to 
the NACK generation are described in Section 3.5.8.2, unless otherwise indicated in the description. The 
description ‘fail to SES’ means the source PDS will indicate to SES that the packet was not successfully 
delivered. SES will generally complete the associated operation in error. 
NACK packets MUST have the pds.nack_code field set to a valid value as specified in Table 3-68. 
Multiple NACK codes are defined to allow tracking the details of what triggered the NACK. For example, 
an implementation may send pds.nack_code = UET_NO_PDC_AVAIL whenever a PDC is not created. Or 
it may set pds.nack_code to UET_NOCCC_AVAIL, UET_NO_BITMAP, etc. 
Upon reception of a NACK packet with valid pds.nack_code, the source MUST perform the source action 
specified in Table 3-68.
