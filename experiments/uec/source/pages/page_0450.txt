3.6.4.8 Congestion Signaling (CSIG) 
Congestion Signaling (CSIG) is an in-band telemetry method that efficiently aggregates and reports per-
switch congestion signals along a packet’s path. CSIG carries an aggregated congestion signal as a tag 
inserted into each packet, updated by switches along its path to expose per-switch congestion state. 
When a CSIG-tagged packet arrives at its destination FEP, the signal value(s) are extracted and passed to 
the transport layer. If the transport congestion control algorithm requires feedback at the source, the 
destination encodes the extracted signal in a CSIG Reflection Header (3.6.9.4). This header is carried 
back to the source within an extended acknowledgement (ACK_CCX or NACK_CCX) generated by the 
transport layer. In this way, congestion information observed along the forward path is reliably returned 
to the sender for use in congestion control, load balancing, or other functions. 
If a sender-based CC algorithm (such as NSCC) is in use at the transport layer, or if other sender-based 
functions (e.g., multi-path load balancing) need the information collected by the CSIG tag, the CSIG-
Reflect() function at the transport layer MUST be enabled. The CSIG-Reflect() function populates the 
CSIG Reflection Header with information extracted by the CSIG-Term() function. The CSIG Reflection 
Header is returned to the source via an ACK or NACK packet generated by the transport. When CSIG-
Reflect() is enabled, the PDS MUST generate extended acknowledgements containing up to 128 bits of 
congestion state (the ACK_CCX and NACK_CCX fields in ACKs and NACKs, respectively). The extended 
congestion state field (pds.ack_ccx_state or pds.nack_ccx_state) carries the CSIG Reflection Header 
back to the source FEP. Section 3.6.9.4 describes the format of the CSIG Reflection Header as well as the 
pds.ack_ccx_state and pds.nack_ccx_state formats used for CSIG Reflection. 
Implementation of the CSIG-Reflect() function is REQUIRED in a CSIG-capable FEP and MUST be enabled 
when NSCC is enabled. CSIG-Reflect() MAY be enabled if NSCC is not enabled. 
If a UET source FEP requires CSIG information to be reflected by the destination FEP, it SHOULD set the 
pds.flags.ar bit when inserting a CSIG tag in a packet.
