On FEP initialization, the following state is initialized for oversubscribed congestion control. These values 
are maintained once for all CCCs from all sources. They are not per CCC. 
Table 3-103 - RCCC Global Destination State for Aggregate Rate Control 
Name Type Default Description 
reference_rate float 1 reference_rate is only updated periodically (at most once 
per 1 RTT). 
increment_stage unsigned int 0 A counter of the number of additive increase phases 
performed since the last multiplicative increase. 
average_delay unsigned int 0 Estimated queueing delay. 
next_rate_change int 0 Time when the reference_rate will be updated. 
last_cc_invocation int 0 Time when the CC was last invoked.
