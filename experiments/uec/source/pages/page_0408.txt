3.5.20.2.6 Single-Packet Read Sequence—SES Medium and Small Headers 
When SES uses the medium (UET_HDR_REQUEST_MEDIUM) or small (UET_HDR_REQUEST_SMALL) 
headers, there is no ses.message_id field. This leads to differences in how reads are processed. Instead 
of using message ID to associate the read response with the read request, the PSN of the request is 
carried in the SES Response header (ses.original_request_psn). These sequences are similar to the 
example in Section 3.5.20.2.5. 
The standard RUD sequence for a single-packet read using SES medium and small headers on a best-
effort network is shown in Figure 3-102. This shows a read with return data larger than 
Max_ACK_Data_Size so the return direction is used to send return data. 
The sequence in the figure proceeds in the same manner as Figure 3-101:
