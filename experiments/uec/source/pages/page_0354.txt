3.5.11.13 pds.mpr (Maximum PSN Range) 
The pds.mpr field specifies the available PSN tracking state at a destination given its currently available 
resources. It is set to a default value of Default_MPR when a PDC is created. The maximum PSN range 
supported is 255, which specifies the maximum MP_Range of 32640 (see Table 3-60). The destination 
may update this value via the ACK_CC pds.mpr field based on locally available resources. 
The pds.mpr field specifies the MP_Range by using the following formula: 
if (pds.mpr == 0)  
    MP_RANGE = Override_MPR_Zero_Value 
else  
    MP_RANGE = pds.mpr *128 packets
