3.5.16.4.1 Close Command 
The initiator sends a Close Command CP to the target to indicate the PDC is being closed. If the target 
accepts a Negotiation CP to assume responsibility for tracking Syn_Retx_Safety_Time, then the 
Remaining_Time is placed in the pds.payload field as illustrated in Figure 3-89. It is encoded in units of 
1 s. Otherwise, the pds.payload field is set to 0x0. 
The Close Command CP triggers an ACK with pds.next_hdr = UET_HDR_CP_ACK. The payload is 
illustrated in Figure 3-90. The fields are defined in Table 3-74.

3.5.16.4.2 Close Request 
The target sends a Close Request CP to the initiator to request the initiator close the PDC. The CP 
pds.payload field is set to 0x0. 
The Close Request CP triggers an ACK with pds.next_hdr = UET_HDR_NONE.
