4.2.9 CSIG Signals 
This section describes each signal, the algorithm for any associated computation, boundary conditions, 
and the signal’s applicability in example use cases. 
In the text that follows, we name each signal according to signal type and the comparison function—
min() or max()—used in CSIG-Compare-and-Update() operations on tags containing that signal. 
4.2.9.1 min(ABW) 
When a source FEP sends a packet with a CSIG tag for signal type min(ABW), and that packet traverses a 
path through the UE fabric, that packet’s CSIG tag records the minimum absolute available bandwidth 
along the path: among all switches along that packet’s path, the minimum quantized absolute available 
bandwidth in bytes per second (Bps) at any output physical port traversed by that packet. Both the 
unquantized and quantized absolute available bandwidth values are represented as integers.
