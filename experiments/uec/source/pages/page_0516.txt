3.6.18 Programmable Congestion Management 
Ultra Ethernet programmable congestion management (PCM) provides support for alternative 
congestion control (CC) and load balancing (LB) algorithms within the transport architecture. PCM is 
designed to support algorithms that reduce congestion and efficiently utilize network resources across 
multiple paths. 
CC support in UE PCM is categorized into two primary mechanisms. The first mechanism governs the 
sending of data within the network by restricting the number of bytes in flight, through either a send 
window or credit scheme. The second optional mechanism limits the send rate. While hybrid 
approaches are possible, the baseline congestion control specified herein limits the number of bytes in 
the network only by using windows for NSCC and credits for RCCC. 
LB support is provided through two approaches: per-packet load balancing, where algorithms are 
invoked for every transmitted and acknowledged request packet, and EV table-based load balancing, 
which relies on a hardware-maintained table of entropy values (EV table). PCM algorithms manipulate 
this table to optimize traffic distribution dynamically. 
A robust congestion management framework must be capable of operating across endpoints handling a 
diverse range of traffic types. Large AI systems frequently encounter mixed workloads consisting of both 
AI and storage traffic. These mixed workloads necessitate an approach that provides fundamental 
quality-of-service (QoS) mechanisms not only within the network at each switch buffer, but also at the 
endpoints to ensure appropriate traffic differentiation and prioritization.
