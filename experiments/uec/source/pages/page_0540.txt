3.6.18.6.4 Control Packets 
PCM algorithms can trigger control packets such as probe packets or credit packets to the peer. Those 
packets are scheduled through the current CCC and thus use the associated window, rate, and EV. 
Table 3-124 - Control Packet Sending 
Function Name (Argument(s)) Description 
int uet_send_ctrl_probe(unsigned int id, unsigned int ev)  Send probe control packet with the specified 
opaque ID. 
int uet_send_ctrl_credit(unsigned int credit)  Send credit control packet with credit amount.
