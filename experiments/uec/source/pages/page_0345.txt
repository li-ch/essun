3.5.10.13 NACK_CCX 
The header format for a NACK_CCX packet is shown in Figure 3-76. The header fields are described in 
Table 3-50. Similar to ACK_CCX described in Section 3.5.10.8, NACK_CCX provides flexibility to enable 
evolution of congestion management schemes in the future. 
 
Table 3-50 - Header Fields for NACK_CCX
