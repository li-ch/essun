2.2.5.2.1 fi_version() API 
The fi_version() API is used to discover the libfabric version. The API returns an encoded version, which 
can be decoded using the FI_MAJOR () and FI_MINOR () macros. The information MAY be used to ensure 
the libfabric version meets the minimum that the application requires. For UET, this minimum should be 
Major Version 2 and Minor Version 0.
