The criteria for using the UET HDR_REQUEST_SMALL header for RMA operations are specified in Section 
2.2.5.3.4.1. The same criteria MUST be applied for atomic operations. The UET HDR_REQUEST_SMALL 
header SHOULD be used only for RMA or atomic operations that satisfy the specified criteria. The 
libfabric mappings for UET HDR_REQUEST_SMALL are shown in Table 2-40.
