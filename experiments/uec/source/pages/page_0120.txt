2.2.5.4.5 Collective APIs 
A collective operation is a group communication exchange that involves multiple peers exchanging data 
with other peers participating in the collective call. Collective operations can be thought of as 
coordinated atomic operations between a set of peer endpoints. 
The collective APIs are required to support UET INC. UET INC support is optional for all profiles. When 
UET INC is supported, the UET provider MUST advertise the FI_COLLECTIVE capability. When UET INC is 
not supported, the UET provider SHOULD NOT advertise the FI_COLLECTIVE capability. 
A provider that supports INC MUST be able to communicate with the INC manager. The 
UET_IM_URL_PRIMARY and UET_IM_URL_SECONDARY environment variables specify URLs used to 
communicate with the INC manager.
