3.3.1 SES Transactions 
Table 3-1 defines the requirements for supporting various transactions to be compliant with each 
profile. Multi-packet transactions such as UET_WRITE, UET_READ, and UET_SEND MUST use a consistent 
Payload MTU size to transport the SES payload. Therefore, a deployment MUST use a consistent Payload 
MTU size across all FEPs communicating in a fabric.
