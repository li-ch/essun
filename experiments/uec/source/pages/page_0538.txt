The PCM runtime delivers received telegrams to algorithms through the algorithm’s registered callback 
function. A single telegram is delivered per invocation. Algorithms determine the telegram type using 
the uet_get_tgm_type() function and the invocation context using the uet_invoke_ctx() function. 
Telegram field values are accessed using the telegram field access functions. Fields MUST be delivered 
to the algorithm in the PCM implementation’s native endian order.
