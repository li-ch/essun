3.3.9 Encapsulation 
Many of the transport components of all profiles inherently rely on consistent lower-level protocol 
encapsulation (e.g., IPv4 vs. IPv6 as network layer encapsulation, UFH_16 vs. UFH_32 for the Unified 
Local Profile, and native UET vs. UDP encapsulation at the transport layer). For example, TSS uses 
confidentiality and encryption offsets for the secure domain specific to the encapsulation type, and CMS 
uses a nominal packet size to calculate bandwidth. An implementation SHOULD use consistent 
encapsulations on all packets on a FEP, PDC, and TSS security domain.
