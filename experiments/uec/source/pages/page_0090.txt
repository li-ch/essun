Table 2-8 - UET Control API JobID Mapping Parameters 
Parameter Name Size (bits) Description 
Flags 8  Valid Flags

          1 => UET Address field is valid 
Bit 1:1 Indicates validity of security bindings field 
          0 => Security bindings field is NOT valid  
          1 => Security bindings field is valid
