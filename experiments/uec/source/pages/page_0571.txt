3.7.8.3 Server KDF Mode 
The server KDF mode is used to assist server key scaling and MUST use the cluster KDF mode 
construction, except destination information is used in the Context. The Label is 0x5532 or ‘U2’ in ASCII 
and the Context is defined as follows: 
• LabelSrv  = 0x5532 or ‘U2’ in ASCII 
• Contextv4 = current_epoch||0x00000000||DestSSI:if ssi-mode==TRUE
