3.6.14.7.2.2 RCCC Aggregate Rate Control Algorithm 
When RCCC Aggregate Rate Control is enabled, the following OnRX(pkt) code must be run on each 
packet arrival in addition to the OnRX(pkt) packet processing described in Section 3.6.14.6. The code 
updates the credit_rate (a FEP global variable, see Table 3-102), which is used to control the frequency 
of credit creation at the receiver as specified in the OnCreditTimer() pseudocode in Section 3.6.14.6). 
OnRX(pkt):   
    if (pkt.csig.t== “max(Delay)”):   
        //UPDATE average delay based on CSIG signal maxDelay 
        average_delay = g * quant_reverse_lookup_for_maxDelay(pkt.csig.s) + 
                       (1-g) * average_delay 
    else: 
        est_delay = 0 
        if (pkt is trimmed): 
            est_delay = trim_delay 
        elif (pkt.ECN marked): 
            est_delay = max_thresh_delay 
        else : 
            est_delay = min_thresh_delay 
 
        average_delay = f * est_delay + (1-f) * average_delay 
 
    delta = now() - last_update 
 
    if (delta > CC_INVOCATION_DELTA): 
        DoOversubscribedCC() 
        last_update = now()
