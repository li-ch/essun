7.4 Redfish for UE Endpoint Manageability 
Remote management of the server can be done via two manageability paths, as shown in Figure 7-3: in-
band or out-of-band management. The in-band path uses the same resources that hosts the operating 
system. The out-of-band path uses dedicated resources that are operationally independent of the state 
of the in-band resources. This path enables the system to be managed before the OS is operational or 
when the OS is non-operational (hung or shutdown). The BMC (baseboard management controller) is 
the component that exposes the Redfish interface to two management entities. The out-of-band 
interface is accessed by the remote client. The in-band interface (host interface) is accessed by the in-
band entities (BIOS, OS, software agent).
