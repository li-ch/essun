2.4.17.4 Monitoring INC Communicator Status 
Switches report communicator failures by setting the oper-status node to FAILED. The IM monitors the 
oper-status node and reports the INC communicator as failed if any switch reports a failure. It is 
RECOMMENDED that the IM set a gNMI subscription to the oper-status node. 
When an INC communicator’s oper-status node changes to FAILED, the failure-description leaf SHOULD 
contain a human-readable description of the failure. 
2.4.17.5 INC Communicator Destruction 
The IM can destroy an INC communicator by deleting the communicator node.
