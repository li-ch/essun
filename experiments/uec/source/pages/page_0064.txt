1.5.1.3 Local Scale-up Network 
Scale-up networks are typically very specialized short-range interconnects that often come with only a 
single or limited tier of switches or possibly no switch at all. 
Historical scale-up networks support I/O coherency that is not always present in all types of 
interconnects. Modern examples used to connect accelerators (e.g., XPUs known as GPUs, FPGAs, or 
specialized SoCs) include AMD’s XGMI, NVIDIA’s NVLINK, Intel’s Xe Link, switched PCIExpress, and CXL 
systems. The capabilities of these networks usually include memory semantics (which is similar to RDMA 
for bulk transfers) at the lowest available latencies (targeting sub-microsecond, for a small-scale or 
programmed memory access). The Unified Local profile can be used to build local scale-up networks 
with Ultra Ethernet. The optimized, compact header formats support high-performance and low-latency 
read/write operations. UE does not specify the user interface to those operations.
