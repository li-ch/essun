2.4.3 INC Operations 
Table 2-49 defines the operations for INC. 
Table 2-49 - INC Collective Operations 
Name Opcode Req Description 
UET_INC_REDUCE 0x00 MUST Reduces values to the root rank 
UET_INC_ALLREDUCE 0x01 MUST Reduces values to all ranks 
UET_INC_BCAST 0x02 Note1 Distributes values to all ranks 
UET_INC_BARRIER 0x03 MUST Synchronizes all ranks 
UET_INC_EXSCAN 0x04  Exclusive scan  
UET_INC_SYNCBCAST 0x05 Note1 Synchronizes all ranks and distributes values to all ranks 
Reserved 0x06-0xEF  Reserved 
Vendor defined 0xF0-0xFF  Vendor-specific operations 
Note: 
1. An implementation MUST support at least one broadcast implementation, either UET_INC_BCAST (where 
non-root FEPs do not synchronize with the SEP, enabling pipelining of multiple BCAST operations) or 
UET_INC_SYNCBCAST (where non-root FEPs synchronize with the SEP using a zero-sized message before 
starting the operation). 
 
Informative Text: 
The UET_INC_SYNCBCAST operation may lend itself to a simpler switch implementation because FEPs 
typically post receive buffers before the broadcast arrives, eliminating the need for the deferrable 
send to be deferred.  In contrast, the UET_INC_BCAST operation allows more flexible use of the 
operation by not forcing a synchronization point.
