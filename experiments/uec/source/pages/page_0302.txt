PDC processing at the initiator and target is largely symmetrical, accepting requests from SES to transmit 
a packet and returning the corresponding SES Response. At the target, SES requests are limited to 
responses to SES read requests (i.e., return data). 
Only the initiator issues a query for an eager window size as only the initiator can transmit Send 
messages. These sequences of related functions are shown in the high-level diagram in Figure 3-54 and 
are described in more detail ahead.

3.5.5 PDS Configuration Parameters 
Table 3-35 contains a summary of the PDS configuration parameters. At least one set of the PDS 
configuration parameters MUST be supported for each FEP. If reserved PDCs are supported, a second 
set of these parameters MUST be supported for each FEP. The reserved pool, discussed in Section 
3.5.18, is used for special services.
