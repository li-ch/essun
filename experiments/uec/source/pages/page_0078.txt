2.1.1.3 In-Network Collectives (INC) 
Various collective operations are utilized in both AI and HPC workloads and *CCL and MPI libraries. 
These operations can be offloaded to the fabric or FEPs to gain performance benefits, such as reduced 
latency or increased throughput, or to gain efficiency benefits such as reduced processing or memory 
utilization. The INC feature requires the specification of software entities and APIs. An INC solution 
includes participation between end-point agents (part of the UEC libfabric provider), an INC manager 
(IM), and switch agents. Ranks interact with the IM using a gRPC API. This interface identifies fabric 
capabilities, supports error handling, and allows members to join and leave collective groups. 
The IM interacts with switch agents using a gRPC API. This interface is used by the IM to identify switch 
capabilities, allocate and deallocate resources for a collective group, and support error handling and 
telemetry.
