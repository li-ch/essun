Two variations on the semantic response with data are used. The first (Figure 3-26) mimics the basic 
semantic response and adds a payload length—to indicate the number of bytes in the packet—and a 
message offset—to indicate where within the message this packet falls. The message ID is used to 
identify the original read request. At the semantic level, all operations—including read operations—are 
packetized based on the Payload MTU. A multi-packet fi_read(), for example, will use the same message 
ID in each packet and use that to issue a single completion at the initiator. This format MUST be used for 
responses with data to requests that include a request length larger than the Payload MTU. This format 
MUST NOT be used to respond to optimized request headers (Figure 3-15), because various fields are 
not available in that request to generate this response.
