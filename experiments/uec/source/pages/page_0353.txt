3.5.11.9 pds.entropy 
The pds.entropy field is used by network switches to select a path through the network. UET provides 
two methods for carrying this entropy field depending on the encapsulation: 
• udp.src_port when UDP encapsulation is used. 
• A UE entropy header (pds.entropy) that immediately follows an IPv4 or IPv6 header when native 
IPv4 or IPv6 encapsulation is used or immediately follows the EtherType 0xE790 when UET runs 
directly over Ethernet. 
The congestion management function assigns the pds.entropy field used in each request packet. ACK 
packets use the pds.entropy field from the packet that triggered the ACK generation. Refer to the CMS 
Section 3.6.16 for more information on how entropy is selected.
