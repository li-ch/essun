# External-reproduction records

One YAML file per public reproduction report, transcribed per
[docs/reproduction-policy.md](../../docs/reproduction-policy.md). The
board on the site's Reproductions page renders from this directory
(`python3 tools/reproduction_board.py`), and the transcription is
validated by `python -m essun.evidence.reproductions <repo-root>`.

There are no records yet — none exist anywhere. When the first public
report lands on the funnel issue, its transcription is added here and
the page shows it on the next render; attempts are listed whether they
succeed, diverge, or stop early.
